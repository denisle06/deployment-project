(~1.5 min) One line per tool. GitHub gives us pull requests, review and history, so every change is traceable. Jenkins is a visible, self-hosted CI server, and its distributed agent gives us a genuinely separate test environment. Docker and Docker Hub: build once, run the same image everywhere. The launch template makes servers reproducible in minutes. Nginx gives weighted canary routing without needing Kubernetes. Prometheus and Grafana are portable, central telemetry. Secrets live in Secrets Manager and Jenkins credentials, never in Git. And we picked canary over blue-green because it limits the blast radius and checks real production traffic before full exposure.
