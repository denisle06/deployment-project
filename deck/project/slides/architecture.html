(~2 min) Everything runs on AWS in Sydney, in one VPC. All three EC2 instances come from ONE launch template; its user-data script installs software based on a Role tag. Left to right is the path of a release: GitHub, Jenkins on the jenkins EC2 builds the Docker image, pushes it to Docker Hub, the test EC2 (a Jenkins agent over SSH) runs the tests, then Jenkins deploys to prod over SSH. On prod, Nginx splits traffic between a stable and a canary container. Underneath: Secrets Manager gives Jenkins the Docker Hub token through an IAM role, so no keys are stored. Prometheus and Grafana also live on the jenkins EC2 and scrape prod over the private network. Security groups reference each other: prod only accepts metrics traffic from the jenkins group, SSH only from team IPs and jenkins. Bottom row maps this to L1 to L4.
