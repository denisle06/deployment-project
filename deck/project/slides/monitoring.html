(~1 min) L2 is production performance instrumentation. On prod, Node Exporter exposes host metrics (CPU, memory, disk, network) and cAdvisor exposes per-container metrics, so we can see stable and canary side by side. Prometheus on the jenkins EC2 scrapes both over the private VPC; the prod security group only lets the jenkins group reach those ports. Grafana shows it with the Node Exporter Full and cAdvisor dashboards. We will open Grafana live at the end of the demo.
