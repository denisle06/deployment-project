(~1.5 min) Pick two or three to tell as stories. Networking: our instances first launched into a private subnet, so no public IP, SSH timed out and the bootstrap script could not download anything; we relaunched into the public subnet with Elastic IPs. The bootstrap could not read the Role tag because instance-metadata tags were off; we resolved the role manually, and the template will take the role as a parameter. The best one: Jenkins agent authentication kept failing; the server log said Invalid user “ubuntu ” with a space: a trailing space in the username. And the upload test failing was a typo in the Supabase URL: exactly what a test stage is for, it never reached production. Secrets throughout: Docker Hub token in Secrets Manager, app settings as Jenkins credentials, nothing in Git.
