(~2 min) Deploy runs over SSH to prod. Jenkins first streams the production settings, stored as a Jenkins secret-file credential, with owner-only permissions. Then it starts the new version as a canary next to the current stable container and waits for readiness. Nginx weights move 10% then 100%. At each stage we fire 50 HTTP probes and check three gates: no 5xx or timeouts, p95 under 2 seconds, and proof the canary actually got traffic; no evidence counts as a failure. All pass: the canary is promoted to stable. Any fail: automatic rollback to 100% stable. Because both containers share a Docker volume for PHP sessions, logged-in users are not kicked out when traffic shifts. There is also a manual rollback script.
